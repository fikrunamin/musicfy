# Ritme Web Companion (`ritme-web/`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Ritme web companion: a mobile-first browser client that creates or joins a Ritme room, shows and edits the shared queue, gives the host their controls, and plays the room in sync (YouTube IFrame player or HTML5 video), or works as a silent remote, served by the Ritme Ktor server from the same origin.

**Architecture:** Pure, unit-tested cores with thin adapters around them. `protocol.ts` mirrors `modules/ritme-protocol` and is held to it by the Kotlin golden fixtures. `RitmeConnection` owns the WebSocket (join, pings, reconnect with backoff and resume token). `sessionReducer` + `Session` hold the server's snapshot (no optimistic updates; stale versions ignored). `PlaybackController` makes a `MediaPlayer` (YouTube IFrame or `<video>` adapter) follow the room using `ClockSync` and the seek-only drift policy, and never sends anything. Preact components only render state and call `SessionApi`. The Docker image builds the web app in a Node stage and copies `dist/` to `/app/web`, where the existing server already serves it at `/` and `/r/{code}`.

**Tech Stack:** TypeScript 5.9.3, Preact 10.29.8, Vite 7.3.8 + @preact/preset-vite 2.10.6, Vitest 4.1.12 (+ jsdom 27.4.0, @testing-library/preact 3.2.6), Playwright 1.65.1, hls.js 1.7.4 (lazy chunk), Node 24 (CI/Docker), JDK 21 + Gradle for the server used by the end-to-end test.

- Feature name **Ritme**. WebSocket `ws(s)://<same origin>/ritme`; share link `<origin>/r/{code}`; deep link `musicfy://ritme/{code}`; search `GET /api/search?q=`.
- `PROTOCOL_VERSION = 1`, `MIN_SUPPORTED_PROTOCOL_VERSION = 1`. JSON discriminator `"type"`; commands are `{"type":"Command","reqId":…,"cmd":{"type":…}}`. Client messages are encoded with every field present, in Kotlin declaration order (byte-identical to the fixtures after `JSON.stringify(JSON.parse(fixture))`).
- Tolerant decoding exactly like `decodeServerMessageOrNull`: unknown message types and malformed JSON → `null` (skip the frame), unknown fields ignored, unknown `MediaKind`/`ErrorCode` → `'UNKNOWN'`, missing fields that have a Kotlin default get that default. `UNKNOWN` entries are shown as "Tidak didukung di versi ini" and never played.
- Media kinds: `YOUTUBE_MUSIC` (IFrame player, small), `YOUTUBE_VIDEO` (IFrame player, large), `URL` (+ `url`; `<video>`, hls.js for `.m3u8` without native HLS; any fatal error or http-on-https → unplayable). `durationMs = 0` = live: position not clamped to an end, never seeked.
- Sync: clock offset from the min-RTT sample of the last 8 Ping/Pong samples (5 pings 200 ms apart on connect, then every 30 s), local clock `performance.now()`. Drift: seek only, when `|expected − actual| > 300 ms`, at most once per 5 s. `force` skips only the 5 s rule and is used when the room's playback changes (new entry, Play/Pause/Seek), when the start anchor is reached, and when the tab becomes visible; snapshots that change only members/queue are not forced; a player returning from an ad or buffering (`playing` event) is checked immediately but not forced, so slow networks cannot loop seek → buffer → seek. New tracks: prepare paused, start at `anchorServerTimeMs`.
- The web client **never sends `TrackEnded`**, never mutates the room on its own (no auto-skip), and does no optimistic updates; `State` with `version <=` the applied one is ignored.
- Autoplay gate: in listen mode the player is created only after tapping "Ketuk untuk ikut dengar". The player is visible (YouTube terms; small player ≥ 200 px tall). Embed errors 2/100/101/150 → entry marked "Tidak bisa diputar di web" locally.
- Reconnect: backoff 1 → 2 → 4 → 8 → 15 s, give up 30 s after the drop ("Terputus dari Ritme"); resume token in `sessionStorage` key `ritme.resume` as `{"code","token"}`; display name in `localStorage` `ritme.name`; mode in `localStorage` `ritme.mode`.
- Server limits the client must respect: Create/Join within 10 s of connecting (sent on open); web rooms start empty (`initialQueue: []`) and add one entry per `Add` (far below the 200-entry batch cap); search is submit-only (30/min/IP; 429 and 503 shown); `QUEUE_FULL` (500 entries or the room-state size cap) → toast "Antrean penuh"; commands are sent only while online in a room; browsers accept multi-MB inbound frames.
- Entries sent in `Add` must pass server validation: title/artist ≤ 300 chars, thumbnail null or https ≤ 512 chars, videoId `[A-Za-z0-9_-]{1,64}`, duration 0..24 h.
- UI copy in Indonesian (all strings in `src/ui/strings.ts`). Mobile-first, 16 px side gutters, touch targets ≥ 44 px, visible focus, `aria-live` toasts, light/dark via `prefers-color-scheme`.
- Privacy: no analytics, no external CDNs, no web fonts. The only third-party requests are the YouTube IFrame API script (`https://www.youtube.com/iframe_api`), the embed (`https://www.youtube-nocookie.com`), thumbnails (`referrerpolicy="no-referrer"`), and URL-entry media. Enforced with a CSP `<meta>` in `index.html`.

```ts
type Json = Record<string, unknown>;

/** Thrown for a malformed known message; parseServerMessage turns it into null. */
class Malformed extends Error {}

function obj(v: unknown): Json {
  if (typeof v !== 'object' || v === null || Array.isArray(v)) throw new Malformed();
  return v as Json;
}

function str(o: Json, key: string): string {
  const v = o[key];
  if (typeof v !== 'string') throw new Malformed();
  return v;
}

function optStr(o: Json, key: string): string | null {
  const v = o[key];
  if (v === undefined || v === null) return null;
  if (typeof v !== 'string') throw new Malformed();
  return v;
}

function num(o: Json, key: string, fallback?: number): number {
  const v = o[key];
  if (v === undefined && fallback !== undefined) return fallback;
  if (typeof v !== 'number' || !Number.isFinite(v)) throw new Malformed();
  return v;
}

function bool(o: Json, key: string, fallback?: boolean): boolean {
  const v = o[key];
  if (v === undefined && fallback !== undefined) return fallback;
  if (typeof v !== 'boolean') throw new Malformed();
  return v;
}

function list<T>(o: Json, key: string, item: (v: unknown) => T): T[] {
  const v = o[key];
  if (v === undefined) return [];
  if (!Array.isArray(v)) throw new Malformed();
  return v.map(item);
}

function lenientEnum<T extends string>(values: readonly T[], raw: unknown, fallback: T): T {
  if (typeof raw !== 'string') throw new Malformed();
  return (values as readonly string[]).includes(raw) ? (raw as T) : fallback;
}

function parseSettings(v: unknown): RoomSettings {
  if (v === undefined) return { guestsCanControl: true };

  return { guestsCanControl: bool(o, 'guestsCanControl', true) };
}

  const o = obj(v);
  return {
    isPlaying: bool(o, 'isPlaying', false),
    positionMs: num(o, 'positionMs', 0),
    anchorServerTimeMs: num(o, 'anchorServerTimeMs', 0),
  };
}

  const o = obj(v);
  return {
    code: str(o, 'code'),
    version: num(o, 'version'),
    hostId: str(o, 'hostId'),
    settings: parseSettings(o.settings),
    members: list(o, 'members', parseMember),
    queue: list(o, 'queue', parseQueueEntry),
    currentEntryId: optStr(o, 'currentEntryId'),
    playback: parsePlayback(o.playback),
  };
}

function decode(o: Json): ServerMessage | null {
  switch (o.type) {
    case 'Welcome':
      return {
        type: 'Welcome',
        memberId: str(o, 'memberId'),
        resumeToken: str(o, 'resumeToken'),
        state: parseRoomState(o.state),
        serverTime: num(o, 'serverTime'),
        protocolVersion: num(o, 'protocolVersion', PROTOCOL_VERSION),
      };
    case 'State':
      return { type: 'State', state: parseRoomState(o.state) };
    case 'Pong':
      return { type: 'Pong', clientTime: num(o, 'clientTime'), serverTime: num(o, 'serverTime') };
    case 'Error':
      return { type: 'Error', reqId: optStr(o, 'reqId'), code: lenientEnum(ERROR_CODES, o.code, 'UNKNOWN') };
    case 'Kicked':
      return { type: 'Kicked' };
    case 'RoomClosed':
      return { type: 'RoomClosed' };
    default:
      return null; // a message type from a newer server: skip it
  }
}

/** Null for unknown message types and malformed JSON, so the caller just skips the frame. */
export function parseServerMessage(text: string): ServerMessage | null {
  try {
    return decode(obj(JSON.parse(text)));
  } catch {
    return null;
  }
}

export function currentEntry(state: RoomState): QueueEntry | null {
  if (state.currentEntryId === null) return null;
  return state.queue.find((e) => e.entryId === state.currentEntryId) ?? null;
}

/** True when the length is unknown (live stream). */
export function isLive(entry: { durationMs: number }): boolean {
  return entry.durationMs <= 0;
}

/** Playback position at serverNow, clamped to the current entry (only at 0 for live entries). */
export function positionAt(state: RoomState, serverNow: number): number {
  const entry = currentEntry(state);
  if (!entry) return 0;
  const { isPlaying, positionMs, anchorServerTimeMs } = state.playback;
  const raw = isPlaying ? positionMs + (serverNow - anchorServerTimeMs) : positionMs;
  if (isLive(entry)) return Math.max(0, raw);
  return Math.min(Math.max(0, raw), entry.durationMs);
}
```

```ts
/**
 * Server clock estimate (spec 2.4). Each Ping/Pong gives rtt = t1 - t0 and
 * offset = serverTime - (t0 + t1) / 2; the offset in use comes from the sample with the smallest
 * rtt among the last WINDOW samples. Local times come from a monotonic clock (performance.now()).
 */
export const CLOCK_WINDOW = 8;

interface Sample {
  rtt: number;
  offset: number;
}

export class ClockSync {
  private samples: Sample[] = [];
  private seeded: number | null = null;

  constructor(private readonly window: number = CLOCK_WINDOW) {}

  /** t0 = local time the Ping was sent (echoed back as clientTime), t1 = local time the Pong arrived. */
  addSample(t0: number, t1: number, serverTime: number): void {
    const rtt = t1 - t0;
    if (rtt < 0) return;
    this.samples.push({ rtt, offset: serverTime - (t0 + t1) / 2 });
    if (this.samples.length > this.window) this.samples.shift();
  }

  /** Rough offset from Welcome.serverTime, used only until the first Pong arrives. */
  seed(serverTime: number, receivedAt: number): void {
    this.seeded = serverTime - receivedAt;
  }

  /** Offset of the best sample, the seed, or null when nothing is known yet. */
  get offset(): number | null {
    if (this.samples.length === 0) return this.seeded;
    let best = this.samples[0];
    for (const s of this.samples) if (s.rtt < best.rtt) best = s;
    return best.offset;
  }

  /** Smallest rtt in the window, or null. */
  get rtt(): number | null {
    if (this.samples.length === 0) return null;
    return Math.min(...this.samples.map((s) => s.rtt));
  }

  serverNow(localNow: number): number {
    return localNow + (this.offset ?? 0);
  }
}
```

```ts
/**
 * Web drift policy (spec 2.5): seek only, when the player is more than SEEK_THRESHOLD_MS away
 * from the room, and at most once every MIN_SEEK_INTERVAL_MS. `force` skips the interval (the
 * room's playback changed, the start anchor was reached, the tab is visible again) but never the
 * threshold.
 */
export const SEEK_THRESHOLD_MS = 300;
export const MIN_SEEK_INTERVAL_MS = 5_000;

export interface DriftInput {
  expectedMs: number;
  actualMs: number;
  nowMs: number;
  lastSeekAtMs: number | null;
  force?: boolean;
}

export function shouldSeek({ expectedMs, actualMs, nowMs, lastSeekAtMs, force = false }: DriftInput): boolean {
  if (Math.abs(expectedMs - actualMs) <= SEEK_THRESHOLD_MS) return false;
  if (force || lastSeekAtMs === null) return true;
  return nowMs - lastSeekAtMs >= MIN_SEEK_INTERVAL_MS;
}
```

```ts
/** A string key/value store; sessionStorage and localStorage can throw (private mode, blocked). */
export interface KeyValueStore {
  get(key: string): string | null;
  set(key: string, value: string): void;
  remove(key: string): void;
}

export function safeStore(getStorage: () => Storage): KeyValueStore {
  return {
    get(key) {
      try {
        return getStorage().getItem(key);
      } catch {
        return null;
      }
    },
    set(key, value) {
      try {
        getStorage().setItem(key, value);
      } catch {
        // Not persisted; the app still works for this page load.
      }
    },
    remove(key) {
      try {
        getStorage().removeItem(key);
      } catch {
        // Nothing to clean up.
      }
    },
  };
}

export function memoryStore(): KeyValueStore {
  const data = new Map<string, string>();
  return {
    get: (key) => data.get(key) ?? null,
    set: (key, value) => void data.set(key, value),
    remove: (key) => void data.delete(key),
  };
}

/** Resume token for the room this tab is in (sessionStorage: per tab, survives reloads). */
export const RESUME_KEY = 'ritme.resume';
/** Display name (localStorage: remembered across visits). */
export const NAME_KEY = 'ritme.name';
/** 'listen' or 'remote' (localStorage). */
export const MODE_KEY = 'ritme.mode';

export interface ResumeInfo {
  code: string;
  token: string;
}

export function readResume(store: KeyValueStore): ResumeInfo | null {
  const raw = store.get(RESUME_KEY);
  if (!raw) return null;
  try {
    const v = JSON.parse(raw) as Partial<ResumeInfo>;
    return typeof v.code === 'string' && typeof v.token === 'string' ? { code: v.code, token: v.token } : null;
  } catch {
    return null;
  }
}

export function writeResume(store: KeyValueStore, info: ResumeInfo): void {
  store.set(RESUME_KEY, JSON.stringify(info));
}
```

- [ ] **Step 4: Implement the connection**

Rules encoded here: Create/Join is sent as soon as the socket opens (the server closes sockets that have not joined within 10 s); a Create session reconnects with `Join` to the created room; a rejection before the first Welcome ends the session with its code, a rejection while resuming ends it as `lost` (except `RATE_LIMITED`, which just waits for the next backoff step); the resume token is cleared on every terminal end except `unreachable` (so "Gabung" can retry with it).

`ritme-web/src/net/connection.ts`:

```ts
import {
  type ClientMessage,
  type Command,
  type ErrorCode,
  type RoomState,
  type ServerMessage,
  type Welcome,
  PROTOCOL_VERSION,
  encodeClientMessage,
  parseServerMessage,
} from '../protocol';
import { type KeyValueStore, RESUME_KEY, readResume, writeResume } from './storage';

/** The subset of the browser WebSocket this client uses, so tests can pass a fake. */
export interface SocketLike {
  readonly readyState: number;
  send(data: string): void;
  close(code?: number, reason?: string): void;
  onopen: ((ev: unknown) => void) | null;
  onmessage: ((ev: { data: unknown }) => void) | null;
  onclose: ((ev: unknown) => void) | null;
  onerror: ((ev: unknown) => void) | null;
}

export type SocketFactory = (url: string) => SocketLike;

export type ConnectionStatus = 'connecting' | 'online' | 'reconnecting';

export type EndReason =
  | { kind: 'left' }
  | { kind: 'kicked' }
  | { kind: 'closed' }
  | { kind: 'lost' }
  | { kind: 'unreachable' }
  | { kind: 'rejected'; code: ErrorCode };

export type ConnectionEvent =
  | { type: 'status'; status: ConnectionStatus }
  | { type: 'welcome'; welcome: Welcome; receivedAt: number }
  | { type: 'state'; state: RoomState }
  | { type: 'pong'; clientTime: number; serverTime: number; receivedAt: number }
  | { type: 'error'; reqId: string | null; code: ErrorCode }
  | { type: 'ended'; reason: EndReason };

export type JoinIntent = { kind: 'create'; name: string } | { kind: 'join'; code: string; name: string };

export interface ConnectionOptions {
  url: string;
  socketFactory: SocketFactory;
  /** sessionStorage in the browser: holds the resume token. */
  storage: KeyValueStore;
  /** Monotonic local clock in ms (performance.now()). */
  now: () => number;
  onEvent: (event: ConnectionEvent) => void;
}

/** Reconnect delays (spec 4.1): 1 → 2 → 4 → 8 → 15 s, giving up 30 s after the drop. */
export const BACKOFF_MS = [1_000, 2_000, 4_000, 8_000, 15_000];
export const RECONNECT_GIVE_UP_MS = 30_000;
/** A socket that has not opened by then counts as a failed attempt. */
export const CONNECT_TIMEOUT_MS = 8_000;
export const PING_BURST = 5;
export const PING_BURST_GAP_MS = 200;
export const PING_INTERVAL_MS = 30_000;

const WS_OPEN = 1;

/**
 * One Ritme session over WebSocket: Create/Join on every (re)connect with the resume token,
 * clock pings, exponential reconnect, and a single terminal `ended` event. Unknown or malformed
 * frames are skipped. Browser WebSockets have no inbound frame limit, so multi-MB snapshots are fine.
 */
export class RitmeConnection {
  private socket: SocketLike | null = null;
  private intent: JoinIntent | null = null;
  private welcomed = false;
  private joined = false;
  private ended = false;
  private attempt = 0;
  private droppedAt: number | null = null;
  private nextReqId = 1;
  private readonly socketTimers = new Set<ReturnType<typeof setTimeout>>();
  private reconnectTimer: ReturnType<typeof setTimeout> | null = null;

  constructor(private readonly opts: ConnectionOptions) {}

  start(intent: JoinIntent): void {
    if (this.intent) throw new Error('RitmeConnection.start called twice');
    this.intent = intent;
    this.emit({ type: 'status', status: 'connecting' });
    this.open();
  }

  /** Sends a command and returns its reqId; dropped (returns null) while not joined. */
  command(cmd: Command): string | null {
    if (!this.joined) return null;
    const reqId = `r${this.nextReqId++}`;
    this.send({ type: 'Command', reqId, cmd });
    return reqId;
  }

  leave(): void {
    if (this.ended) return;
    if (this.joined) this.send({ type: 'Leave' });
    this.finish({ kind: 'left' });
  }

  private open(): void {
    const socket = this.opts.socketFactory(this.opts.url);
    this.socket = socket;
    this.joined = false;
    let opened = false;
    this.later(CONNECT_TIMEOUT_MS, () => {
      if (!opened) this.drop(socket);
    });
    socket.onopen = () => {
      if (this.socket !== socket) return;
      opened = true;
      this.send(this.joinMessage());
      for (let i = 0; i < PING_BURST; i++) this.later(i * PING_BURST_GAP_MS, () => this.ping());
      this.later(PING_INTERVAL_MS, () => this.pingLoop());
    };
    socket.onmessage = (ev) => {
      if (this.socket !== socket || typeof ev.data !== 'string') return;
      const message = parseServerMessage(ev.data);
      if (message) this.handle(message);
    };
    socket.onclose = () => this.drop(socket);
    socket.onerror = () => {
      // A close event always follows.
    };
  }

  private joinMessage(): ClientMessage {
    const intent = this.intent!;
    if (intent.kind === 'create') {
      return {
        type: 'Create',
        protocolVersion: PROTOCOL_VERSION,
        name: intent.name,
        initialQueue: [],
        startIndex: 0,
        startPositionMs: 0,
      };
    }
    const resume = readResume(this.opts.storage);
    return {
      type: 'Join',
      protocolVersion: PROTOCOL_VERSION,
      code: intent.code,
      name: intent.name,
      resumeToken: resume && resume.code === intent.code ? resume.token : null,
    };
  }

  private handle(message: ServerMessage): void {
    switch (message.type) {
      case 'Welcome': {
        this.joined = true;
        this.welcomed = true;
        this.attempt = 0;
        this.droppedAt = null;
        // Reconnects always Join the room this Welcome is for, with its token.
        this.intent = { kind: 'join', code: message.state.code, name: this.intent!.name };
        writeResume(this.opts.storage, { code: message.state.code, token: message.resumeToken });
        this.emit({ type: 'welcome', welcome: message, receivedAt: this.opts.now() });
        this.emit({ type: 'status', status: 'online' });
        return;
      }
      case 'State':
        if (this.joined) this.emit({ type: 'state', state: message.state });
        return;
      case 'Pong':
        this.emit({
          type: 'pong',
          clientTime: message.clientTime,
          serverTime: message.serverTime,
          receivedAt: this.opts.now(),
        });
        return;
      case 'Error':
        if (this.joined) {
          this.emit({ type: 'error', reqId: message.reqId, code: message.code });
        } else if (this.welcomed && message.code === 'RATE_LIMITED') {
          // A reconnect hit a connection cap: the server closes, and the backoff tries again.
        } else {
          this.finish(this.welcomed ? { kind: 'lost' } : { kind: 'rejected', code: message.code });
        }
        return;
      case 'Kicked':
        this.finish({ kind: 'kicked' });
        return;
      case 'RoomClosed':
        this.finish({ kind: 'closed' });
        return;
    }
  }

  private drop(socket: SocketLike): void {
    if (this.socket !== socket) return;
    this.detach(socket);
    if (this.ended) return;
    if (!this.welcomed) {
      this.finish({ kind: 'unreachable' });
      return;
    }
    if (this.droppedAt === null) {
      this.droppedAt = this.opts.now();
      this.emit({ type: 'status', status: 'reconnecting' });
    }
    const delay = BACKOFF_MS[Math.min(this.attempt, BACKOFF_MS.length - 1)];
    this.attempt++;
    if (this.opts.now() + delay - this.droppedAt >= RECONNECT_GIVE_UP_MS) {
      this.finish({ kind: 'lost' });
      return;
    }
    this.reconnectTimer = setTimeout(() => {
      this.reconnectTimer = null;
      if (!this.ended) this.open();
    }, delay);
  }

  private finish(reason: EndReason): void {
    if (this.ended) return;
    this.ended = true;
    if (reason.kind !== 'unreachable') this.opts.storage.remove(RESUME_KEY);
    if (this.reconnectTimer !== null) clearTimeout(this.reconnectTimer);
    if (this.socket) this.detach(this.socket);
    this.emit({ type: 'ended', reason });
  }

  /** Forgets a socket: no more callbacks, its timers cleared, closed if still open. */
  private detach(socket: SocketLike): void {
    socket.onopen = socket.onmessage = socket.onclose = socket.onerror = null;
    for (const t of this.socketTimers) clearTimeout(t);
    this.socketTimers.clear();
    if (this.socket === socket) this.socket = null;
    this.joined = false;
    try {
      socket.close(1000, 'bye');
    } catch {
      // Already closed.
    }
  }

  private ping(): void {
    this.send({ type: 'Ping', clientTime: Math.floor(this.opts.now()) });
  }

  private pingLoop(): void {
    this.ping();
    this.later(PING_INTERVAL_MS, () => this.pingLoop());
  }

  private later(ms: number, fn: () => void): void {
    const timer = setTimeout(() => {
      this.socketTimers.delete(timer);
      fn();
    }, ms);
    this.socketTimers.add(timer);
  }

  private send(message: ClientMessage): void {
    const socket = this.socket;
    if (!socket || socket.readyState !== WS_OPEN) return;
    socket.send(encodeClientMessage(message));
  }

  private emit(event: ConnectionEvent): void {
    this.opts.onEvent(event);
  }
}

/** ws(s)://<this origin>/ritme */
export function ritmeSocketUrl(location: { protocol: string; host: string }): string {
  return `${location.protocol === 'https:' ? 'wss' : 'ws'}://${location.host}/ritme`;
}
```

```ts
import type { QueueEntry, RoomState } from '../protocol';

/**
 * Client-side copy of the permission table (spec 2.3), used only to hide buttons. The server
 * checks again and answers FORBIDDEN, so a stale view can never do harm.
 */
export function isHost(room: RoomState, memberId: string | null): boolean {
  return memberId !== null && room.hostId === memberId;
}

/** Play, Pause, Seek, Next, Previous, PlayEntry, Move, and Remove of other people's entries. */
export function canControl(room: RoomState, memberId: string | null): boolean {
  return isHost(room, memberId) || room.settings.guestsCanControl;
}

export function canRemove(room: RoomState, memberId: string | null, entry: QueueEntry): boolean {
  return entry.addedBy === memberId || canControl(room, memberId);
}

export interface QueueView {
  played: QueueEntry[];
  current: QueueEntry | null;
  upcoming: QueueEntry[];
}

/** Splits the queue around the current entry; with nothing current everything is upcoming. */
export function splitQueue(room: RoomState): QueueView {
  const index = room.queue.findIndex((e) => e.entryId === room.currentEntryId);
  if (index < 0) return { played: [], current: null, upcoming: room.queue };
  return {
    played: room.queue.slice(0, index),
    current: room.queue[index],
    upcoming: room.queue.slice(index + 1),
  };
}

/**
 * The Move target that swaps an upcoming entry with the one before it, or null when it is already
 * first. `afterEntryId: null` means "right after the current entry" (or the very top with nothing
 * current), exactly as the server reads it.
 */
export function moveUpTarget(room: RoomState, entryId: string): { afterEntryId: string | null } | null {
  const currentIndex = room.queue.findIndex((e) => e.entryId === room.currentEntryId);
  const index = room.queue.findIndex((e) => e.entryId === entryId);
  if (index <= currentIndex + 1) return null;
  const anchorIndex = index - 2;
  if (anchorIndex <= currentIndex) return { afterEntryId: null };
  return { afterEntryId: room.queue[anchorIndex].entryId };
}

/** The Move target that swaps an upcoming entry with the one after it, or null when it is last. */
export function moveDownTarget(room: RoomState, entryId: string): { afterEntryId: string | null } | null {
  const currentIndex = room.queue.findIndex((e) => e.entryId === room.currentEntryId);
  const index = room.queue.findIndex((e) => e.entryId === entryId);
  if (index <= currentIndex || index + 1 >= room.queue.length) return null;
  return { afterEntryId: room.queue[index + 1].entryId };
}
```

```ts
import type { ConnectionEvent, ConnectionStatus, EndReason } from '../net/connection';
import type { ErrorCode, RoomState } from '../protocol';

export type NoticeKey = 'forbidden' | 'rateLimited' | 'queueFull' | 'invalid' | 'failed' | 'linkCopied';

export interface Notice {
  id: number;
  key: NoticeKey;
}

export interface SessionState {
  phase: 'idle' | 'connecting' | 'in-room' | 'ended';
  connection: ConnectionStatus;
  memberId: string | null;
  room: RoomState | null;
  serverProtocolVersion: number | null;
  ended: EndReason | null;
  /** Entries this browser cannot play (embed blocked, media error); local only, never sent. */
  unplayable: Readonly<Record<string, true>>;
  notice: Notice | null;
}

export type SessionAction =
  | ConnectionEvent
  | { type: 'start' }
  | { type: 'reset' }
  | { type: 'mark-unplayable'; entryId: string }
  | { type: 'notice'; key: NoticeKey };

export const initialSession: SessionState = {
  phase: 'idle',
  connection: 'connecting',
  memberId: null,
  room: null,
  serverProtocolVersion: null,
  ended: null,
  unplayable: {},
  notice: null,
};

export function noticeFor(code: ErrorCode): NoticeKey {
  switch (code) {
    case 'FORBIDDEN':
      return 'forbidden';
    case 'RATE_LIMITED':
      return 'rateLimited';
    case 'QUEUE_FULL':
      return 'queueFull';
    case 'INVALID':
      return 'invalid';
    default:
      return 'failed';
  }
}

function withNotice(state: SessionState, key: NoticeKey): SessionState {
  return { ...state, notice: { id: (state.notice?.id ?? 0) + 1, key } };
}

/**
 * Pure session state machine. The server's snapshot is the only truth: no optimistic updates, and
 * a State whose version is not newer than the applied one is ignored (spec 2.2).
 */
export function sessionReducer(state: SessionState, action: SessionAction): SessionState {
  switch (action.type) {
    case 'start':
      return { ...initialSession, phase: 'connecting', notice: state.notice };
    case 'reset':
      return { ...initialSession, notice: state.notice };
    case 'status':
      return { ...state, connection: action.status };
    case 'welcome': {
      const sameRoom = state.room?.code === action.welcome.state.code;
      return {
        ...state,
        phase: 'in-room',
        memberId: action.welcome.memberId,
        room: action.welcome.state,
        serverProtocolVersion: action.welcome.protocolVersion,
        unplayable: sameRoom ? state.unplayable : {},
      };
    }
    case 'state':
      if (!state.room || action.state.code !== state.room.code) return state;
      if (action.state.version <= state.room.version) return state;
      return { ...state, room: action.state };
    case 'pong':
      return state;
    case 'error':
      return withNotice(state, noticeFor(action.code));
    case 'ended':
      return { ...state, phase: 'ended', ended: action.reason, room: null, memberId: null };
    case 'mark-unplayable':
      if (state.unplayable[action.entryId]) return state;
      return { ...state, unplayable: { ...state.unplayable, [action.entryId]: true } };
    case 'notice':
      return withNotice(state, action.key);
  }
}
```

```ts
  transferHost(memberId: string): void;
  endRoom(): void;
  markUnplayable(entryId: string): void;
  notify(key: NoticeKey): void;
}

/**
 * The one place that owns the connection, the clock and the session state. There is deliberately
 * no way to send TrackEnded from here: the web client never reports track ends (spec 2.6).
 */
export class Session implements SessionApi {
  private state: SessionState = initialSession;
  private readonly listeners = new Set<() => void>();
  private conn: ConnectionLike | null = null;
  readonly clock: ClockSync;

  constructor(private readonly deps: SessionDeps) {
    this.clock = deps.clock ?? new ClockSync();
  }

  getState = (): SessionState => this.state;

  subscribe = (listener: () => void): (() => void) => {
    this.listeners.add(listener);
    return () => this.listeners.delete(listener);
  };

  serverNow = (): number => this.clock.serverNow(this.deps.now());

  create(name: string): void {
    this.begin({ kind: 'create', name });
  }

  join(code: string, name: string): void {
    this.begin({ kind: 'join', code, name });
  }

  leave(): void {
    this.conn?.leave();
  }

  /** Back to the start screen after the session ended. */
  dismiss(): void {
    if (this.state.phase === 'ended') this.dispatch({ type: 'reset' });
  }

  play(): void {
    this.send({ type: 'Play' });
  }
  pause(): void {
    this.send({ type: 'Pause' });
  }
  seek(positionMs: number): void {
    this.send({ type: 'Seek', positionMs: Math.max(0, Math.round(positionMs)) });
  }
  next(): void {
    this.send({ type: 'Next' });
  }
  previous(): void {
    this.send({ type: 'Previous' });
  }
  playEntry(entryId: string): void {
    this.send({ type: 'PlayEntry', entryId });
  }
  add(entry: NewEntry, playNext: boolean): void {
    this.send({ type: 'Add', entries: [entry], playNext });
  }
  remove(entryId: string): void {
    this.send({ type: 'Remove', entryId });
  }
  move(entryId: string, afterEntryId: string | null): void {
    this.send({ type: 'Move', entryId, afterEntryId });
  }
  setGuestsCanControl(value: boolean): void {
    this.send({ type: 'SetSettings', settings: { guestsCanControl: value } });
  }
  kick(memberId: string): void {
    this.send({ type: 'Kick', memberId });
  }
  transferHost(memberId: string): void {
    this.send({ type: 'TransferHost', memberId });
  }
  endRoom(): void {
    this.send({ type: 'EndRoom' });
  }

  markUnplayable(entryId: string): void {
    this.dispatch({ type: 'mark-unplayable', entryId });
  }

  notify(key: NoticeKey): void {
    this.dispatch({ type: 'notice', key });
  }

  private begin(intent: JoinIntent): void {
    if (this.state.phase === 'connecting' || this.state.phase === 'in-room') return;
    this.dispatch({ type: 'start' });
    const conn = this.deps.connect((event) => {
      if (this.conn === conn) this.onEvent(event);
    });
    this.conn = conn;
    conn.start(intent);
  }

  private onEvent(event: ConnectionEvent): void {
    if (event.type === 'pong') this.clock.addSample(event.clientTime, event.receivedAt, event.serverTime);
    if (event.type === 'welcome') this.clock.seed(event.welcome.serverTime, event.receivedAt);
    if (event.type === 'ended') this.conn = null;
    this.dispatch(event);
  }

  private send(cmd: Command): void {
    if (this.state.phase !== 'in-room' || this.state.connection !== 'online') return;
    this.conn?.command(cmd);
  }

  private dispatch(action: Parameters<typeof sessionReducer>[1]): void {
    const next = sessionReducer(this.state, action);
    if (next === this.state) return;
    this.state = next;
    for (const listener of this.listeners) listener();
  }
}
```

```ts
import type { NewEntry } from '../protocol';

/** One item of GET /api/search?q= (ritme-server Search.kt SearchResult). */
export interface SearchResult {
  videoId: string;
  title: string;
  artist: string;
  durationMs: number;
  thumbnailUrl: string | null;
}

export type SearchFailure = 'invalid' | 'rate-limited' | 'busy' | 'failed';

export type SearchOutcome = { ok: true; results: SearchResult[] } | { ok: false; reason: SearchFailure };

export const MAX_QUERY_LENGTH = 200;

/** Server-side entry limits (ritme-server README "Entries"); exceeding them makes Add INVALID. */
const MAX_TEXT_LENGTH = 300;
const MAX_THUMBNAIL_URL_LENGTH = 512;
const MAX_DURATION_MS = 86_400_000;
const VIDEO_ID = /^[A-Za-z0-9_-]{1,64}$/;

function parseResult(v: unknown): SearchResult | null {
  if (typeof v !== 'object' || v === null) return null;
  const o = v as Record<string, unknown>;
  if (typeof o.videoId !== 'string' || typeof o.title !== 'string' || typeof o.artist !== 'string') return null;
  if (typeof o.durationMs !== 'number') return null;
  return {
    videoId: o.videoId,
    title: o.title,
    artist: o.artist,
    durationMs: o.durationMs,
    thumbnailUrl: typeof o.thumbnailUrl === 'string' ? o.thumbnailUrl : null,
  };
}

export async function searchSongs(
  query: string,
  fetchImpl: typeof fetch = fetch,
  signal?: AbortSignal,
): Promise<SearchOutcome> {
  const q = query.trim();
  if (q.length === 0 || q.length > MAX_QUERY_LENGTH) return { ok: false, reason: 'invalid' };
  let response: Response;
  try {
    response = await fetchImpl(`/api/search?q=${encodeURIComponent(q)}`, {
      signal,
      headers: { Accept: 'application/json' },
    });
  } catch {
    return { ok: false, reason: 'failed' };
  }
  if (response.status === 400) return { ok: false, reason: 'invalid' };
  if (response.status === 429) return { ok: false, reason: 'rate-limited' };
  if (response.status === 503) return { ok: false, reason: 'busy' };
  if (!response.ok) return { ok: false, reason: 'failed' };
  try {
    const body: unknown = await response.json();
    if (!Array.isArray(body)) return { ok: false, reason: 'failed' };
    return { ok: true, results: body.map(parseResult).filter((r): r is SearchResult => r !== null) };
  } catch {
    return { ok: false, reason: 'failed' };
  }
}

/**
 * A search result as an Add entry that passes the server's validation: text trimmed to 300
 * chars, thumbnails dropped unless https and at most 512 chars, duration within 0..24 h.
 * Null when the videoId itself is unusable.
 */
export function toNewEntry(result: SearchResult): NewEntry | null {
  if (!VIDEO_ID.test(result.videoId)) return null;
  const title = result.title.trim().slice(0, MAX_TEXT_LENGTH);
  if (title.length === 0) return null;
  const thumb = result.thumbnailUrl;
  return {
    videoId: result.videoId,
    title,
    artist: result.artist.trim().slice(0, MAX_TEXT_LENGTH),
    thumbnailUrl: thumb && thumb.startsWith('https://') && thumb.length <= MAX_THUMBNAIL_URL_LENGTH ? thumb : null,
    durationMs: Math.min(Math.max(0, Math.round(result.durationMs)), MAX_DURATION_MS),
    kind: 'YOUTUBE_MUSIC',
    url: null,
  };
}
```

```ts
export type PlayableSource = { kind: 'youtube'; videoId: string } | { kind: 'video'; url: string; hls: boolean };

export type PlayerKind = PlayableSource['kind'];

export type PlayerEvent = { type: 'playing' } | { type: 'paused' } | { type: 'unplayable' };

/**
 * A media player adapter (YouTube IFrame or HTML5 <video>). Calls made before the underlying
 * player is ready are remembered and applied once it is.
 */
export interface MediaPlayer {
  /** Prepares the source paused at startMs (null: the player's default, e.g. the live edge). */
  load(source: PlayableSource, startMs: number | null): void;
  play(): void;
  pause(): void;
  seek(ms: number): void;
  /** Current position, or null while unknown (not ready yet). */
  currentMs(): number | null;
  destroy(): void;
}

export type PlayerFactory = (kind: PlayerKind, onEvent: (event: PlayerEvent) => void) => MediaPlayer;
```

```ts
import type { QueueEntry } from '../protocol';
import type { PlayableSource } from './types';

export type Playability =
  | { playable: true; source: PlayableSource; large: boolean }
  | { playable: false; reason: 'unsupported' | 'insecure' };

const HLS_PATH = /\.m3u8$/i;

/**
 * How (and whether) this browser can play an entry. YouTube kinds use the IFrame player
 * (video kinds shown large); URL entries use <video>, with hls.js for .m3u8. UNKNOWN kinds from a
 * newer protocol are unsupported, and http:// media cannot play on an https page (mixed content).
 */
export function playability(entry: QueueEntry, pageIsHttps: boolean): Playability {
  switch (entry.kind) {
    case 'YOUTUBE_MUSIC':
    case 'YOUTUBE_VIDEO':
      if (!entry.videoId) return { playable: false, reason: 'unsupported' };
      return { playable: true, source: { kind: 'youtube', videoId: entry.videoId }, large: entry.kind === 'YOUTUBE_VIDEO' };
    case 'URL': {
      let url: URL;
      try {
        url = new URL(entry.url ?? '');
      } catch {
        return { playable: false, reason: 'unsupported' };
      }
      if (url.protocol !== 'https:' && url.protocol !== 'http:') return { playable: false, reason: 'unsupported' };
      if (pageIsHttps && url.protocol === 'http:') return { playable: false, reason: 'insecure' };
      return { playable: true, source: { kind: 'video', url: url.href, hls: HLS_PATH.test(url.pathname) }, large: true };
    }
    default:
      return { playable: false, reason: 'unsupported' };
  }
}
```

```ts
import { type QueueEntry, type RoomState, currentEntry, isLive, positionAt } from '../protocol';
import { shouldSeek } from '../sync/drift';
import { playability } from './playable';
import type { MediaPlayer, PlayerEvent, PlayerFactory, PlayerKind } from './types';

export const DRIFT_CHECK_MS = 1_000;
/** No 'playing' event this long after play(): the browser probably wants a tap on the player. */
export const NEEDS_TAP_AFTER_MS = 4_000;

export interface ControllerOptions {
  createPlayer: PlayerFactory;
  /** Estimated server time (Session.serverNow). */
  serverNow: () => number;
  pageIsHttps: boolean;
  onUnplayable: (entryId: string) => void;
  onNeedsTap: (needsTap: boolean) => void;
}

/**
 * Makes the local player follow the room (spec 5.4). It only reads room state and never sends
 * anything: no commands, and never TrackEnded. New entries are prepared paused and started at
 * the anchor; drift is corrected by seeking only (sync/drift.ts); live entries follow play/pause
 * but are never seeked.
 */
export class PlaybackController {
  private player: MediaPlayer | null = null;
  private playerKind: PlayerKind | null = null;
  private loadedEntryId: string | null = null;
  private room: RoomState | null = null;
  private entry: QueueEntry | null = null;
  private wantPlaying = false;
  private playerPlaying = false;
  private lastSeekAt: number | null = null;
  /** Entry + playback fields last applied; a forced re-sync happens only when they change. */
  private appliedKey: string | null = null;
  private startTimer: ReturnType<typeof setTimeout> | null = null;
  private tapTimer: ReturnType<typeof setTimeout> | null = null;
  private readonly driftTimer: ReturnType<typeof setInterval>;

  constructor(private readonly opts: ControllerOptions) {
    this.driftTimer = setInterval(() => this.correct(false), DRIFT_CHECK_MS);
  }

  /** Call with every new room snapshot (and when the unplayable set changes). */
  update(room: RoomState | null, unplayable: Readonly<Record<string, true>>): void {
    this.room = room;
    const entry = room ? currentEntry(room) : null;
    const verdict = entry ? playability(entry, this.opts.pageIsHttps) : null;
    if (!entry || !verdict || !verdict.playable || unplayable[entry.entryId]) {
      this.entry = null;
      this.appliedKey = null;
      this.halt();
      return;
    }
    this.entry = entry;
    if (this.playerKind !== verdict.source.kind) {
      this.player?.destroy();
      this.player = this.opts.createPlayer(verdict.source.kind, (e) => this.onPlayerEvent(e));
      this.playerKind = verdict.source.kind;
      this.loadedEntryId = null;
      this.playerPlaying = false;
    }
    if (this.loadedEntryId !== entry.entryId) {
      this.loadedEntryId = entry.entryId;
      this.lastSeekAt = null;
      const start = isLive(entry) ? null : positionAt(room!, this.opts.serverNow());
      this.player!.load(verdict.source, start);
    }
    // Snapshots that only change members or the queue must not bypass the 5 s seek interval.
    const { isPlaying, positionMs, anchorServerTimeMs } = room!.playback;
    const key = `${entry.entryId}|${isPlaying}|${positionMs}|${anchorServerTimeMs}`;
    const changed = key !== this.appliedKey;
    this.appliedKey = key;
    this.apply(changed);
  }

  /** Tab visible again, or anything else that calls for an immediate re-sync. */
  resync(): void {
    this.apply(true);
  }

  destroy(): void {
    clearInterval(this.driftTimer);
    this.clearStart();
    this.clearTap();
    this.player?.destroy();
    this.player = null;
    this.playerKind = null;
    this.loadedEntryId = null;
  }

  /** force: playback changed, the anchor was reached, or the tab came back (skips the 5 s rule). */
  private apply(force: boolean): void {
    this.clearStart();
    const room = this.room;
    const player = this.player;
    if (!room || !player || !this.entry) return;
    const now = this.opts.serverNow();
    const { isPlaying, anchorServerTimeMs } = room.playback;
    if (isPlaying && now >= anchorServerTimeMs) {
      this.wantPlaying = true;
      player.play();
      this.armTap();
      this.correct(force);
      return;
    }
    this.wantPlaying = false;
    this.clearTap();
    player.pause();
    this.correct(force);
    if (isPlaying) this.startTimer = setTimeout(() => this.apply(true), anchorServerTimeMs - now);
  }

  /** Paused, or waiting for the anchor: correct toward the room position, playing or not. */
  private correct(force: boolean): void {
    const room = this.room;
    const player = this.player;
    const entry = this.entry;
    if (!room || !player || !entry || isLive(entry)) return;
    if (!force && !this.wantPlaying) return;
    const actual = player.currentMs();
    if (actual === null) return;
    const now = this.opts.serverNow();
    const expected = positionAt(room, now);
    if (shouldSeek({ expectedMs: expected, actualMs: actual, nowMs: now, lastSeekAtMs: this.lastSeekAt, force })) {
      player.seek(expected);
      this.lastSeekAt = now;
    }
  }

  private onPlayerEvent(event: PlayerEvent): void {
    switch (event.type) {
      case 'playing':
        this.playerPlaying = true;
        this.clearTap();
        this.opts.onNeedsTap(false);
        // Back from an ad or buffering: check right away instead of at the next tick. Not forced,
        // so a slow network cannot loop seek -> buffer -> playing -> seek faster than every 5 s.
        if (this.wantPlaying) this.correct(false);
        else this.player?.pause();
        return;
      case 'paused':
        this.playerPlaying = false;
        return;
      case 'unplayable':
        if (this.loadedEntryId) this.opts.onUnplayable(this.loadedEntryId);
        return;
    }
  }

  /** Stops output for "nothing playable now"; keeps the player for the next entry. */
  private halt(): void {
    this.clearStart();
    this.clearTap();
    this.wantPlaying = false;
    this.player?.pause();
  }

  private armTap(): void {
    if (this.playerPlaying || this.tapTimer !== null) return;
    this.tapTimer = setTimeout(() => {
      this.tapTimer = null;
      if (this.wantPlaying && !this.playerPlaying) this.opts.onNeedsTap(true);
    }, NEEDS_TAP_AFTER_MS);
  }

  private clearTap(): void {
    if (this.tapTimer !== null) clearTimeout(this.tapTimer);
    this.tapTimer = null;
  }

  private clearStart(): void {
    if (this.startTimer !== null) clearTimeout(this.startTimer);
    this.startTimer = null;
  }
}
```

```ts
import type { MediaPlayer, PlayableSource, PlayerEvent } from './types';

/** The only third-party script the app loads. */
export const IFRAME_API_URL = 'https://www.youtube.com/iframe_api';
/** Privacy-enhanced embed host: no YouTube cookies until the viewer interacts. */
export const EMBED_HOST = 'https://www.youtube-nocookie.com';
/** 2 invalid id, 100 removed/private, 101 and 150 embedding not allowed by the owner. */
export const UNPLAYABLE_ERRORS = [2, 100, 101, 150];

const STATE_PLAYING = 1;
const STATE_PAUSED = 2;

export interface YTPlayer {
  cueVideoById(options: { videoId: string; startSeconds?: number }): void;
  playVideo(): void;
  pauseVideo(): void;
  seekTo(seconds: number, allowSeekAhead: boolean): void;
  getCurrentTime(): number;
  destroy(): void;
}

export interface YTPlayerOptions {
  host: string;
  width: string;
  height: string;
  playerVars: Record<string, string | number>;
  events: {
    onReady: () => void;
    onStateChange: (event: { data: number }) => void;
    onError: (event: { data: number }) => void;
  };
}

export interface YTNamespace {
  Player: new (element: HTMLElement, options: YTPlayerOptions) => YTPlayer;
}

type YTWindow = Window & { YT?: YTNamespace; onYouTubeIframeAPIReady?: () => void };

/** Loads the IFrame API script at most once per page; rejects (and allows a retry) if it fails. */
export function createYouTubeApiLoader(doc: Document, win: YTWindow): () => Promise<YTNamespace> {
  let pending: Promise<YTNamespace> | null = null;
  return () => {
    if (win.YT?.Player) return Promise.resolve(win.YT);
    if (!pending) {
      pending = new Promise<YTNamespace>((resolve, reject) => {
        const previous = win.onYouTubeIframeAPIReady;
        win.onYouTubeIframeAPIReady = () => {
          previous?.();
          resolve(win.YT!);
        };
        const script = doc.createElement('script');
        script.src = IFRAME_API_URL;
        script.async = true;
        script.onerror = () => {
          pending = null;
          script.remove();
          reject(new Error('YouTube IFrame API failed to load'));
        };
        doc.head.appendChild(script);
      });
    }
    return pending;
  };
}

export const loadYouTubeApi: () => Promise<YTNamespace> =
  typeof document === 'undefined'
    ? () => Promise.reject(new Error('no document'))
    : createYouTubeApiLoader(document, window as YTWindow);

/** MediaPlayer over the YouTube IFrame Player API; queues calls until the player is ready. */
export function createYouTubePlayer(
  container: HTMLElement,
  onEvent: (event: PlayerEvent) => void,
  loadApi: () => Promise<YTNamespace> = loadYouTubeApi,
): MediaPlayer {
  const mount = container.ownerDocument.createElement('div');
  container.appendChild(mount);
  let yt: YTPlayer | null = null;
  let ready = false;
  let failed = false;
  let destroyed = false;
  let pendingLoad: { videoId: string; startMs: number | null } | null = null;
  let wantPlay = false;

  const cue = (videoId: string, startMs: number | null) => {
    yt!.cueVideoById(startMs === null ? { videoId } : { videoId, startSeconds: startMs / 1000 });
  };

  loadApi().then(
    (YT) => {
      if (destroyed) return;
      yt = new YT.Player(mount, {
        host: EMBED_HOST,
        width: '100%',
        height: '100%',
        playerVars: { playsinline: 1, rel: 0, origin: container.ownerDocument.location.origin },
        events: {
          onReady: () => {
            ready = true;
            if (pendingLoad) cue(pendingLoad.videoId, pendingLoad.startMs);
            pendingLoad = null;
            if (wantPlay) yt!.playVideo();
          },
          onStateChange: (e) => {
            if (e.data === STATE_PLAYING) onEvent({ type: 'playing' });
            else if (e.data === STATE_PAUSED) onEvent({ type: 'paused' });
          },
          onError: (e) => {
            if (UNPLAYABLE_ERRORS.includes(e.data)) onEvent({ type: 'unplayable' });
          },
        },
      });
    },
    () => {
      failed = true;
      if (!destroyed && pendingLoad) onEvent({ type: 'unplayable' });
    },
  );

  return {
    load(source: PlayableSource, startMs: number | null) {
      if (source.kind !== 'youtube') throw new Error('YouTube player got a non-YouTube source');
      if (failed) {
        queueMicrotask(() => onEvent({ type: 'unplayable' }));
        return;
      }
      if (ready) cue(source.videoId, startMs);
      else pendingLoad = { videoId: source.videoId, startMs };
    },
    play() {
      wantPlay = true;
      if (ready) yt!.playVideo();
    },
    pause() {
      wantPlay = false;
      if (ready) yt!.pauseVideo();
    },
    seek(ms: number) {
      if (ready) yt!.seekTo(ms / 1000, true);
    },
    currentMs() {
      return ready ? yt!.getCurrentTime() * 1000 : null;
    },
    destroy() {
      destroyed = true;
      yt?.destroy();
      mount.remove();
    },
  };
}
```

```ts
import type { MediaPlayer, PlayableSource, PlayerEvent } from './types';

/** The subset of hls.js used here (loaded on demand, only for .m3u8 without native HLS). */
export interface HlsLike {
  loadSource(url: string): void;
  attachMedia(media: HTMLMediaElement): void;
  on(event: string, handler: (event: string, data: { fatal?: boolean }) => void): void;
  destroy(): void;
}

export interface HlsConstructor {
  new (): HlsLike;
  isSupported(): boolean;
  Events: { ERROR: string };
}

const loadHlsJs = (): Promise<HlsConstructor> =>
  import('hls.js').then((m) => m.default as unknown as HlsConstructor);

/**
 * MediaPlayer over a plain <video> element for URL entries. mp4/webm play natively (no CORS
 * needed); HLS uses native support (Safari) or hls.js, which needs CORS on the stream host. Any
 * fatal error marks the entry unplayable.
 */
export function createVideoPlayer(
  container: HTMLElement,
  onEvent: (event: PlayerEvent) => void,
  loadHls: () => Promise<HlsConstructor> = loadHlsJs,
): MediaPlayer {
  const video = container.ownerDocument.createElement('video');
  video.playsInline = true;
  video.controls = true;
  video.preload = 'auto';
  video.className = 'player-video';
  container.appendChild(video);

  let hls: HlsLike | null = null;
  let generation = 0;
  let wantPlay = false;
  let pendingStartMs: number | null = null;

  video.addEventListener('playing', () => onEvent({ type: 'playing' }));
  video.addEventListener('pause', () => onEvent({ type: 'paused' }));
  video.addEventListener('error', () => onEvent({ type: 'unplayable' }));
  video.addEventListener('loadedmetadata', () => {
    if (pendingStartMs !== null) video.currentTime = pendingStartMs / 1000;
    pendingStartMs = null;
    if (wantPlay) tryPlay();
  });

  const tryPlay = () => {
    // NotAllowedError (no user gesture yet) is handled by the controller's "tap" hint.
    void Promise.resolve(video.play()).catch(() => {});
  };

  const teardown = () => {
    hls?.destroy();
    hls = null;
    video.removeAttribute('src');
  };

  return {
    load(source: PlayableSource, startMs: number | null) {
      if (source.kind !== 'video') throw new Error('Video player got a non-video source');
      const mine = ++generation;
      teardown();
      pendingStartMs = startMs;
      const nativeHls = video.canPlayType('application/vnd.apple.mpegurl') !== '';
      if (source.hls && !nativeHls) {
        loadHls().then(
          (Hls) => {
            if (mine !== generation) return;
            if (!Hls.isSupported()) {
              onEvent({ type: 'unplayable' });
              return;
            }
            const instance = new Hls();
            instance.on(Hls.Events.ERROR, (_event, data) => {
              if (data.fatal) onEvent({ type: 'unplayable' });
            });
            instance.loadSource(source.url);
            instance.attachMedia(video);
            hls = instance;
          },
          () => {
            if (mine === generation) onEvent({ type: 'unplayable' });
          },
        );
      } else {
        video.src = source.url;
      }
    },
    play() {
      wantPlay = true;
      if (video.readyState >= 1) tryPlay();
    },
    pause() {
      wantPlay = false;
      video.pause();
    },
    seek(ms: number) {
      if (video.readyState >= 1) video.currentTime = ms / 1000;
      else pendingStartMs = ms;
    },
    currentMs() {
      return video.readyState >= 1 ? video.currentTime * 1000 : null;
    },
    destroy() {
      generation++;
      teardown();
      video.remove();
    },
  };
}
```

```ts
/** 0:07, 3:33, 1:02:03 */
export function formatMs(ms: number): string {
  const total = Math.max(0, Math.floor(ms / 1000));
  const h = Math.floor(total / 3600);
  const m = Math.floor((total % 3600) / 60);
  const s = total % 60;
  const ss = String(s).padStart(2, '0');
  return h > 0 ? `${h}:${String(m).padStart(2, '0')}:${ss}` : `${m}:${ss}`;
}

export const ROOM_CODE_ALPHABET = '23456789ABCDEFGHJKLMNPQRSTUVWXYZ';
const CODE = new RegExp(`^[${ROOM_CODE_ALPHABET}]{6}$`);

/** Uppercased, spaces and dashes removed; null unless it is a valid 6-character room code. */
export function normalizeCode(raw: string): string | null {
  const code = raw.replace(/[\s-]/g, '').toUpperCase();
  return CODE.test(code) ? code : null;
}

/** Trimmed display name of 1–32 characters, or null. */
export function normalizeName(raw: string): string | null {
  const name = raw.trim();
  return name.length >= 1 && name.length <= 32 ? name : null;
}

/** The room code in /r/{code}, or null. */
export function codeFromPath(pathname: string): string | null {
  const match = /^\/r\/([^/]+)\/?$/.exec(pathname);
  return match ? normalizeCode(decodeURIComponent(match[1])) : null;
}
```

```ts
import type { SessionState } from '../session/reducer';
import type { SessionApi } from '../session/session';

/** Re-renders on every session change. */
export function useSessionState(session: SessionApi): SessionState {
  const [state, setState] = useState(session.getState());
  useEffect(() => {
    setState(session.getState());
    return session.subscribe(() => setState(session.getState()));
  }, [session]);
  return state;
}

/** Server time, refreshed every `intervalMs` (for progress bars). */
export function useServerNow(session: SessionApi, intervalMs = 500): number {
  const [now, setNow] = useState(session.serverNow());
  useEffect(() => {
    const id = setInterval(() => setNow(session.serverNow()), intervalMs);
    return () => clearInterval(id);
  }, [session, intervalMs]);
  return now;
}
```

```tsx
import type { SessionApi } from '../session/session';
import { normalizeCode, normalizeName } from './format';

  state: SessionState;
  /** From /r/{code}; prefills the code and shows the "open in app" button. */
  routeCode: string | null;

export function HomeScreen({ session, state, routeCode, prefs }: Props) {
  const [name, setName] = useState(prefs.get(NAME_KEY) ?? '');
  const [code, setCode] = useState(routeCode ?? '');
  const [error, setError] = useState<string | null>(null);
  const busy = state.phase === 'connecting';
  const ended = state.phase === 'ended' && state.ended ? endText(state.ended) : null;

  const validName = (): string | null => {
    const n = normalizeName(name);
    if (!n) setError(t.nameInvalid);
    else prefs.set(NAME_KEY, n);
    return n;
  };

    setError(null);
    const n = validName();
    if (!n) return;

    e.preventDefault();

    if (!n) return;

    if (!c) {
      setError(t.codeInvalid);
      return;

    session.dismiss();
    session.join(c, n);

      <header class="home-header">
        <h1>{routeCode ? t.invited : t.appName}</h1>
```

```ts
import type { QueueEntry } from '../protocol';
import { playability } from '../player/playable';
import { t } from './strings';

/** Why this browser will not play an entry, or null when it can. */
export function unplayableLabel(entry: QueueEntry, unplayable: Readonly<Record<string, true>>, pageIsHttps: boolean): string | null {
  const verdict = playability(entry, pageIsHttps);
  if (!verdict.playable) return verdict.reason === 'insecure' ? t.insecure : t.unsupported;
  return unplayable[entry.entryId] ? t.unplayableWeb : null;
}

export function memberName(members: { id: string; name: string }[], id: string, me: string | null): string {
  if (id === me) return t.you;
  return members.find((m) => m.id === id)?.name ?? '—';
}

export const pageIsHttps = (): boolean => typeof location !== 'undefined' && location.protocol === 'https:';
```

```tsx
function Row({ entry, session, room, memberId, unplayable, online, pageIsHttps, upcoming }: Props & { entry: QueueEntry; upcoming: boolean }) {
  const control = online && canControl(room, memberId);
  const removable = online && canRemove(room, memberId, entry);
  const up = upcoming ? moveUpTarget(room, entry.entryId) : null;
  const down = upcoming ? moveDownTarget(room, entry.entryId) : null;
  const label = unplayableLabel(entry, unplayable, pageIsHttps);
  return (
    <li class="queue-row">
      <Thumb entry={entry} />
      <div class="queue-text">
        <span class="title">{entry.title}</span>
        <span class="muted small">
          {[entry.artist, isLive(entry) ? t.live : formatMs(entry.durationMs), t.addedBy(memberName(room.members, entry.addedBy, memberId))]
            .filter(Boolean)
            .join(' · ')}
        </span>
        {label && <span class="badge">{label}</span>}
      </div>
      <div class="queue-actions">
        {control && (
          <button type="button" class="icon-btn" aria-label={`${t.playNow}: ${entry.title}`} onClick={() => session.playEntry(entry.entryId)}>
            ▶
          </button>
        )}
        {control && up && (
          <button type="button" class="icon-btn" aria-label={`${t.moveUp}: ${entry.title}`} onClick={() => session.move(entry.entryId, up.afterEntryId)}>
            ▲
          </button>
        )}
        {control && down && (
          <button type="button" class="icon-btn" aria-label={`${t.moveDown}: ${entry.title}`} onClick={() => session.move(entry.entryId, down.afterEntryId)}>
            ▼
          </button>
```

```ts
/** Asks the browser to keep the screen on while listening (re-acquired when the tab is visible again). */
export function keepScreenOn(): () => void {
  if (!('wakeLock' in navigator)) return () => {};
  let sentinel: WakeLockSentinel | null = null;
  let active = true;
  const acquire = () => {
    if (!active || document.visibilityState !== 'visible') return;
    navigator.wakeLock.request('screen').then(
      (s) => {
        if (active) sentinel = s;
        else void s.release();
      },
      () => {},
    );
  };
  document.addEventListener('visibilitychange', acquire);
  acquire();
  return () => {
    active = false;
    document.removeEventListener('visibilitychange', acquire);
    void sentinel?.release().catch(() => {});
  };
}
```

```tsx
/** The visible player (never hidden, per YouTube's terms); exists only after the tap gate. */
function PlayerHost({ session, room, unplayable, pageIsHttps }: Omit<Props, 'mode' | 'onModeChange'>) {
  const container = useRef<HTMLDivElement>(null);
  const controller = useRef<PlaybackController | null>(null);
  const [needsTap, setNeedsTap] = useState(false);

  useEffect(() => {
    const el = container.current!;
    const c = new PlaybackController({
      createPlayer: (kind, onEvent) => (kind === 'youtube' ? createYouTubePlayer(el, onEvent) : createVideoPlayer(el, onEvent)),
      serverNow: () => session.serverNow(),
      pageIsHttps,
      onUnplayable: (entryId) => session.markUnplayable(entryId),
      onNeedsTap: setNeedsTap,
    });
    controller.current = c;
    const onVisible = () => {
      if (document.visibilityState === 'visible') c.resync();
    };
    document.addEventListener('visibilitychange', onVisible);
    const release = keepScreenOn();
    return () => {
      document.removeEventListener('visibilitychange', onVisible);
      release();
      c.destroy();
      controller.current = null;
    };
  }, [session, pageIsHttps]);

  useEffect(() => {
    controller.current?.update(room, unplayable);
  }, [room, unplayable]);

  const entry = currentEntry(room);
  const verdict = entry ? playability(entry, pageIsHttps) : null;
  const large = verdict?.playable === true && verdict.large;
  const hidden = !verdict?.playable || (entry !== null && unplayable[entry.entryId] === true);

  return (
    <>
      <div ref={container} class={`player ${large ? 'player-large' : 'player-small'}`} hidden={hidden} />
```

```tsx
  }, [state.phase, state.room?.code]);

  // Reloaded inside a room: resume with the token from this tab.
  useEffect(() => {
    const code = codeFromPath(location.pathname);
    const name = normalizeName(prefs.get(NAME_KEY) ?? '');
    if (code && name && readResume(tabStore)?.code === code) session.join(code, name);
  }, []);

  return (
    <>
      {state.phase === 'in-room' && state.room ? (
        <RoomScreen session={session} state={{ ...state, room: state.room }} prefs={prefs} />
      ) : (
        <HomeScreen session={session} state={state} routeCode={codeFromPath(path)} prefs={prefs} />
      )}
      <Toast notice={state.notice} />
    </>
  );
}
```

````markdown
# Ritme web

Browser companion for Ritme (listen together): create or join a room, see and edit the shared
queue, control playback (as permitted by the host), and listen in sync through the YouTube IFrame
player, or use it as a silent remote. It is served by the Ritme server from the same origin
(`/`, `/r/{code}`), so the WebSocket (`/ritme`) and search (`/api/search`) need no CORS.

## Develop

Node 24 and, for the server, JDK 21.

```bash
./gradlew -p ritme-server run          # from the repo root: server on :8080
cd ritme-web && npm ci && npm run dev  # http://localhost:5173 (proxies /ritme and /api to :8080)
```

## Test

```bash
npm test           # Vitest: protocol vs. golden fixtures, clock, drift, reducer, connection, players, UI
npm run build      # tsc --noEmit + vite build -> dist/
npm run e2e        # Playwright: builds and starts the real server on :47821 serving dist/ (run build first)
```

`src/protocol.ts` mirrors `modules/ritme-protocol`. Its tests read
`modules/ritme-protocol/fixtures/*.json`, so a protocol change made on one side only fails CI.

## How sync works

- Clock: 5 pings 200 ms apart on connect, then every 30 s; the offset comes from the lowest-RTT
  sample of the last 8 (`src/sync/clock.ts`).
- Playback follows the room snapshot only (`src/player/controller.ts`): new tracks are prepared
  paused and start at the server's anchor; drift over 300 ms is fixed by seeking, at most every
  5 s (room seeks, track changes and returning to the tab re-sync at once; the end of an ad is
  checked immediately). Live entries are never seeked.
- The web client never reports track ends and never changes the room by itself.

## Privacy

No analytics, no cookies of our own, no external fonts or CDNs. The only third-party requests are
the YouTube IFrame API script and the privacy-enhanced embed (`youtube-nocookie.com`) in listen
mode, thumbnails (sent without a referrer), and the media of `URL` entries. A Content Security
Policy in `index.html` enforces this. The display name is kept in `localStorage`, the room's
resume token in `sessionStorage` (this tab only).
````
