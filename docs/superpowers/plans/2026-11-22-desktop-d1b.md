# Desktop D1b: core:model, core:database, core:resolver, core:designsystem, desktopApp — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the database model, the stream resolver and the theme tokens into shared modules, and ship a desktop skeleton that opens its own Room database, reads settings and shows InnerTube search results, without changing the Android app's behaviour.

**Architecture:** Logic modules are plain `kotlin("jvm")` modules (`id("kotlin")`), as in D1a. Room entities move to `core:model`. The Android `@Database`/DAO/migrations stay in `app/`. Desktop gets its own Room database in `core:database` with the same entities and a schema-parity test. The resolver (`YTPlayerUtils` + cipher/PoToken/n-transform) moves to `core:resolver` behind `JsRuntime`/`BotGuardRuntime` session interfaces. The WebView implementations stay in `app/`. Only `core:designsystem` is Kotlin Multiplatform (Android + `jvm("desktop")`), because Compose UI has to be compiled for each platform. Spec: `docs/superpowers/specs/2026-11-22-desktop-d1-core-modules-design.md`. Its "Revisi setelah pemetaan kode" section overrides the rest of the spec.

**Tech Stack:** Gradle 9.3.1, AGP 9.0.0 (`com.android.kotlin.multiplatform.library` for the KMP module), Kotlin 2.3.10, KSP 2.3.5, Room 2.8.4 (+ `androidx.sqlite:sqlite-bundled` 2.6.2 on desktop), androidx Compose 1.10.2 / Material3 1.5.0-alpha18 (app), Compose Multiplatform 1.10.1 (maps to Jetpack Compose 1.10.2) with CMP Material3 1.10.0-alpha05, Koin 4.2.2, OkHttp 5.3.2, JUnit 4.13.2, JDK 21.

## Plan-level deviations from the spec

1. **The Android `@Database` and DAO cannot be shared with desktop without changing behaviour.** This is verified in the `room-compiler-2.8.4` bytecode. `Context.isAndroidOnlyTarget()` is true only when the KSP platform is JVM **and** `android.content.Context` is on the classpath. In any other compilation, `InternalQueryProcessor`, `ShortcutFunctionProcessor` and `TransactionFunctionProcessor` fail with "Only suspend functions are allowed in DAOs declared in source sets targeting non-Android platforms." "Any other compilation" covers a pure JVM module, the JVM half of "compiled twice", and a KMP `jvm("desktop")` target. `DatabaseDao` has about 100 blocking functions that are called synchronously all over `app/`. So:
   - Entities, views, `Converters`, `MediaMetadata`, `PersistQueue` and `String.resize` move to the JVM module `core:model`, with FQNs unchanged.
   - `InternalDatabase`, `DatabaseDao`, `SpeedDialDao`, `MusicDatabase` and all migrations stay in `app/`. They remain Android-only.
   - Desktop gets `DesktopMusicDatabase` (JVM `core:database`): the same entities and views, version 39, and a `suspend`/`Flow` DAO. A test asserts that its exported schema equals `app/schemas/.../39.json`.
   - Task 2 is still the time-boxed spike the spec asks for. It confirms the rule on (a) KMP and (b) a JVM compilation, proves this approach (c), and records the decision in the spec. If the spike disagrees, stop and revise this plan.
2. **`@RawQuery fun raw(SupportSQLiteQuery)` stays Android-only** in `DatabaseDao`, which stays in `app/`. The desktop DAO has no raw queries. D3 can add a `suspend` `RoomRawQuery` if desktop needs `wal_checkpoint`.
3. **`MigrationTestHelper` (v38→39, v24→39) is replaced by a schema identity-hash test plus the manual upgrade install.** Android's Room code and migrations are not edited. An unchanged identity hash means Room opens existing databases exactly as before. The app has no `androidTest` setup and no emulator is available to agents.
4. **`core:model` contains Room entities, not "models without Room".** `MediaMetadata.toSongEntity()` and `Song.toMediaMetadata()` tie the model to the entities (spec Revisi #3). Entities keep `@Immutable` through `androidx.compose.runtime:runtime-annotation:1.10.2`, which publishes a JVM variant with the same FQN.
5. **`JsRuntime` is session-shaped, not `evaluate(script)`.** Today's JS bridges are callback-based: `CipherWebView` loads player.js with exported sig/n functions, `EjsNTransformSolver.SolverWebView` loads the EJS solver, and `PoTokenWebView` runs BotGuard. `evaluate(String)` would mean rewriting them. Instead, the interfaces mirror what the WebViews already do (`loadCipher`, `loadNSolver`, `BotGuardRuntime.newSession`), so the Android implementations are the existing classes plus `override`.
6. **Resolver singletons stay Kotlin `object`s** (`YTPlayerUtils`, `CipherDeobfuscator`, `PlayerJsFetcher`, `EjsNTransformSolver`, `BotDetectionMitigator`). They are configured once via `ResolverRuntime.install(ResolverPlatform)` instead of constructor injection. This keeps the static call sites in App.kt, MusicService, DownloadUtil, RecapSnippetPlayer, CipherSettingsScreen, PlaybackDiagnosticsScreen, MorphingCover and YouTubeVideoLookup. Tests use `install` + `internal resetForTests()` hooks.
7. **`android.util.Log.i` calls in the resolver go through `ResolverPlatform.releaseLog`.** On Android this is still `Log.i`, which, unlike Timber, also logs in release builds. Behaviour is preserved.
8. **Desktop CI uses `:desktopApp:compileKotlin`, not `compileKotlinDesktop`.** `desktopApp` is a plain JVM module with the Compose plugin, not KMP. `build-logic/` and `checkModuleBoundaries` stay deferred: there is exactly one KMP module, and JVM modules cannot compile `android.*`.
9. **Fonts stay per platform.** Android keeps `R.font` Inter. Desktop uses `FontFamily.Default` until D3, because Compose Resources would be a new resource pipeline. `core:designsystem` takes the font family as a parameter.
10. **Smoke, upgrade and screenshot checks are manual steps** marked "Manual (needs a device)". Agents skip them and list them in the PR description.

```kotlin
package com.example.musicfy.db

import org.junit.Assert.assertEquals
import org.junit.Assert.assertTrue
import org.junit.Test
import java.io.File

/**
 * Room refuses to open (or destructively resets) a database whose identity hash differs from the
 * one compiled into the app. Moving entities between modules must therefore leave the exported
 * schema byte-for-byte the same; this pins the hash KSP writes on every build.
 */
class SchemaIdentityTest {
    private val schema = File("schemas/com.example.musicfy.db.InternalDatabase/39.json")
    private val golden = File("src/test/resources/room/InternalDatabase-39.identityHash")

    @Test
    fun exportedSchemaIsVersion39() {
        assertTrue("missing $schema - did KSP run?", schema.exists())
        assertTrue(Regex("\"version\"\\s*:\\s*39\\b").containsMatchIn(schema.readText()))
    }

    @Test
    fun identityHashMatchesBaseline() {
        val hash = Regex("\"identityHash\"\\s*:\\s*\"([0-9a-f]{32})\"")
            .find(schema.readText())
            ?.groupValues
            ?.get(1)
        assertEquals(golden.readText().trim(), hash)
    }
}
```

`app/src/test/kotlin/com/example/musicfy/models/PersistedModelsSerializationTest.kt`:

```kotlin
package com.example.musicfy.models

import org.junit.Assert.assertEquals
import org.junit.Assert.assertTrue
import org.junit.Test
import java.io.ByteArrayOutputStream
import java.io.File
import java.io.ObjectInputStream
import java.io.ObjectOutputStream
import java.io.ObjectStreamClass
import java.time.LocalDateTime

/**
 * MusicService saves the queue with Java serialization. If a class's stream identity changes (its
 * serialVersionUID, or its fields), every user's saved queue fails to restore after the update.
 * Run with -PupdateGolden=true only on code whose serialized form is known-good.
 */
class PersistedModelsSerializationTest {
    private val uidGolden = File("src/test/resources/serialization/serial-version-uids.golden.txt")
    private val queueGolden = File("src/test/resources/serialization/persist-queue.golden.bin")
    private val update = System.getProperty("updateGolden") == "true"

    private val serializedClasses = listOf(
        "com.example.musicfy.models.MediaMetadata",
        "com.example.musicfy.models.MediaMetadata\$Artist",
        "com.example.musicfy.models.MediaMetadata\$Album",
        "com.example.musicfy.models.PersistQueue",
        "com.example.musicfy.models.QueueType",
        "com.example.musicfy.models.QueueType\$LIST",
        "com.example.musicfy.models.QueueType\$YOUTUBE",
        "com.example.musicfy.models.QueueType\$YOUTUBE_ALBUM_RADIO",
        "com.example.musicfy.models.QueueType\$LOCAL_ALBUM_RADIO",
        "com.example.musicfy.models.QueueData",
        "com.example.musicfy.models.QueueData\$YouTubeData",
        "com.example.musicfy.models.QueueData\$YouTubeAlbumRadioData",
        "com.example.musicfy.models.QueueData\$LocalAlbumRadioData",
    )

    private fun sampleQueue() = PersistQueue(
        title = "Golden queue",
        items = listOf(
            MediaMetadata(
                id = "dQw4w9WgXcQ",
                title = "Never Gonna Give You Up",
                artists = listOf(MediaMetadata.Artist(id = "UCuAXFkgsw1L7xaCfnd5JJOw", name = "Rick Astley")),
                duration = 213,
                thumbnailUrl = "https://i.ytimg.com/vi/dQw4w9WgXcQ/hqdefault.jpg",
                album = MediaMetadata.Album(id = "MPREb_golden", title = "Whenever You Need Somebody"),
                setVideoId = "set-1",
                musicVideoType = "MUSIC_VIDEO_TYPE_ATV",
                explicit = false,
                liked = true,
                likedDate = LocalDateTime.of(2026, 11, 22, 10, 30, 0),
                inLibrary = LocalDateTime.of(2026, 1, 2, 3, 4, 5),
                libraryAddToken = "add-token",
                libraryRemoveToken = "remove-token",
                suggestedBy = "radio",
                localUri = null,
            ),
        ),
        mediaItemIndex = 0,
        position = 42_000L,
        queueType = QueueType.YOUTUBE_ALBUM_RADIO,
        queueData = QueueData.YouTubeAlbumRadioData(
            playlistId = "RDAMPLgolden",
            albumSongCount = 12,
            continuation = "cont",
            firstTimeLoaded = true,
        ),
    )

    @Test
    fun serialVersionUidsMatchGolden() {
        val actual = serializedClasses.joinToString("\n") {
            "$it=${ObjectStreamClass.lookup(Class.forName(it)).serialVersionUID}"
        }
        if (update) {
            uidGolden.parentFile.mkdirs()
            uidGolden.writeText(actual + "\n")
            return
        }
        assertEquals(uidGolden.readText().trim(), actual)
    }

    @Test
    fun goldenQueueStillDeserializes() {
        if (update) {
            queueGolden.parentFile.mkdirs()
            val bytes = ByteArrayOutputStream()
            ObjectOutputStream(bytes).use { it.writeObject(sampleQueue()) }
            queueGolden.writeBytes(bytes.toByteArray())
            return
        }
        val restored = ObjectInputStream(queueGolden.inputStream()).use { it.readObject() as PersistQueue }
        val expected = sampleQueue()
        assertEquals(expected.title, restored.title)
        assertEquals(expected.items, restored.items)
        assertEquals(expected.mediaItemIndex, restored.mediaItemIndex)
        assertEquals(expected.position, restored.position)
        assertEquals(expected.queueData, restored.queueData)
        // Plain Kotlin `object`s deserialize as fresh instances, so compare by type, not identity.
        assertTrue(restored.queueType is QueueType.YOUTUBE_ALBUM_RADIO)
    }
}
```

```kotlin
package com.example.musicfy.core.resolver

import java.io.ByteArrayOutputStream

/**
 * Port of android.net.Uri.encode / Uri.decode (libcore UriCodec), so moved code builds the same
 * URLs on every platform. Not URLEncoder: that turns ' ' into '+' and escapes "~!*'()".
 */
object UriCodec {
    private const val HEX = "0123456789ABCDEF"
    private const val ALLOWED = "_-!.~'()*"

    fun encode(s: String): String {
        val out = StringBuilder(s.length)
        for (b in s.toByteArray(Charsets.UTF_8)) {
            val c = b.toInt() and 0xFF
            val ch = c.toChar()
            if (c < 0x80 && (ch in 'a'..'z' || ch in 'A'..'Z' || ch in '0'..'9' || ch in ALLOWED)) {
                out.append(ch)
            } else {
                out.append('%').append(HEX[c shr 4]).append(HEX[c and 0x0F])
            }
        }
        return out.toString()
    }

    /** '+' stays '+'. Malformed escapes become U+FFFD exactly as Android does. */
    fun decode(s: String): String {
        val out = StringBuilder(s.length)
        val pending = ByteArrayOutputStream()
        fun flush() {
            if (pending.size() == 0) return
            out.append(String(pending.toByteArray(), Charsets.UTF_8))
            pending.reset()
        }
        var i = 0
        while (i < s.length) {
            val c = s[i++]
            if (c != '%') {
                flush()
                out.append(c)
                continue
            }
            var value = 0
            for (j in 0 until 2) {
                if (i >= s.length) {
                    flush()
                    out.append('�')
                    return out.toString()
                }
                val digit = hexValue(s[i++])
                if (digit < 0) {
                    flush()
                    out.append('�')
                    break
                }
                value = value * 16 + digit
            }
            // Android writes the accumulated byte even after an invalid digit; kept for parity.
            pending.write(value and 0xFF)
        }
        flush()
        return out.toString()
    }

    private fun hexValue(c: Char): Int = when (c) {
        in '0'..'9' -> c - '0'
        in 'a'..'f' -> c - 'a' + 10
        in 'A'..'F' -> c - 'A' + 10
        else -> -1
    }
}
```

```kotlin
package com.example.musicfy.core.resolver

import com.music.innertube.NewPipeExtractor
import com.music.innertube.YouTube
import com.music.innertube.models.IpVersion
import com.music.innertube.models.YouTubeClient
import com.music.innertube.models.response.PlayerResponse
import okhttp3.Dns
import okhttp3.OkHttpClient
import java.io.IOException
import java.net.Inet4Address
import java.net.Inet6Address
import java.net.InetAddress
import java.net.Proxy
import java.net.ProxySelector
import java.net.SocketAddress
import java.net.URI
import java.util.concurrent.TimeUnit

class YouTubeResolverBackend : ResolverBackend {
    private val httpClient: OkHttpClient = OkHttpClient.Builder()
        .dns(object : Dns {
            override fun lookup(hostname: String): List<InetAddress> {
                val addresses = Dns.SYSTEM.lookup(hostname)
                return when (YouTube.ipVersion) {
                    IpVersion.IPV4 -> addresses.filter { it is Inet4Address }.ifEmpty { addresses }
                    IpVersion.IPV6 -> addresses.filter { it is Inet6Address }.ifEmpty { addresses }
                    IpVersion.AUTO -> addresses
                }
            }
        })
        .proxySelector(object : ProxySelector() {
            override fun select(uri: URI?): List<Proxy> = listOfNotNull(YouTube.proxy ?: Proxy.NO_PROXY)
            override fun connectFailed(uri: URI?, sa: SocketAddress?, ioe: IOException?) {
                ResolverLog.tag(TAG).e(ioe, "Proxy connection failed for URI: $uri")
            }
        })
        .proxyAuthenticator { _, response ->
            YouTube.proxyAuth?.let { auth ->
                response.request.newBuilder()
                    .header("Proxy-Authorization", auth)
                    .build()
            } ?: response.request
        }
        .connectTimeout(15, TimeUnit.SECONDS)
        .readTimeout(15, TimeUnit.SECONDS)
        .build()

    override suspend fun player(
        videoId: String,
        playlistId: String?,
        client: YouTubeClient,
        signatureTimestamp: Int?,
        poToken: String?,
    ): Result<PlayerResponse> = YouTube.player(videoId, playlistId, client, signatureTimestamp, poToken)

    override suspend fun refreshVisitorData(): Result<String> = YouTube.refreshVisitorData()

    override fun signatureTimestamp(videoId: String): Result<Int> = NewPipeExtractor.getSignatureTimestamp(videoId)

    override fun newPipeStreamUrl(format: PlayerResponse.StreamingData.Format, videoId: String): String? =
        NewPipeExtractor.getStreamUrl(format, videoId)

    override fun newPipeStreamUrls(videoId: String): List<Pair<Int, String>> = YouTube.getNewPipeStreamUrls(videoId)

    /**
     * The headers matter: googlevideo validates Origin/Referer against the client named in the
     * url, so probing without them can fail on a url that plays perfectly well. HEAD is not
     * usable here - googlevideo answers it with 403 even for good urls - so this is a ranged GET.
     */
    override fun validateStatus(url: String, headers: Map<String, String>): Boolean {
        ResolverLog.tag(TAG).d("Validating stream URL status")
        try {
            val requestBuilder = okhttp3.Request.Builder()
                .get()
                .url(url)
                .header("Range", "bytes=0-0")

            headers.forEach { (name, value) -> requestBuilder.header(name, value) }
            if (headers["User-Agent"] == null) {
                requestBuilder.header("User-Agent", YouTubeClient.USER_AGENT_WEB)
            }

            YouTube.cookie?.let { cookie ->
                requestBuilder.addHeader("Cookie", cookie)
            }

            httpClient.newCall(requestBuilder.build()).execute().use {
                val isSuccessful = it.isSuccessful || it.code == 206
                ResolverLog.tag(TAG).d("Stream URL validation result: ${if (isSuccessful) "Success" else "Failed"} (${it.code})")
                return isSuccessful
            }
        } catch (e: Exception) {
            ResolverLog.tag(TAG).e(e, "Stream URL validation failed with exception")
            e.printStackTrace()
        }
        return false
    }

    private companion object {
        const val TAG = "YTPlayerUtils"
    }
}
```

```kotlin
// CipherDeobfuscator.kt

package com.example.musicfy.utils.cipher

import com.example.musicfy.core.resolver.CipherSession
import com.example.musicfy.core.resolver.ResolverLog
import com.example.musicfy.core.resolver.ResolverRuntime
import com.example.musicfy.core.resolver.UriCodec

object CipherDeobfuscator {
    private const val TAG = "musicfy_CipherDeobfusc"

    private var cipherWebView: CipherSession? = null
    private var currentPlayerHash: String? = null

    suspend fun deobfuscateStreamUrl(signatureCipher: String, videoId: String): String? {
        return try {
            deobfuscateInternal(signatureCipher, videoId, isRetry = false)
        } catch (e: Exception) {
            ResolverLog.tag(TAG).e(e, "Cipher deobfuscation failed, retrying with fresh JS: ${e.message}")

            try {
                PlayerJsFetcher.invalidateCache()
                closeWebView()
                deobfuscateInternal(signatureCipher, videoId, isRetry = true)
            } catch (retryE: Exception) {
                ResolverLog.tag(TAG).e(retryE, "Cipher deobfuscation retry also failed: ${retryE.message}")
                null
            }
        }
    }

    private suspend fun deobfuscateInternal(signatureCipher: String, videoId: String, isRetry: Boolean): String? {

        val params = parseQueryParams(signatureCipher)
        val obfuscatedSig = params["s"]
        val sigParam = params["sp"] ?: "signature"
        val baseUrl = params["url"]

        if (obfuscatedSig == null || baseUrl == null) {
            ResolverLog.tag(TAG).e("Could not parse signatureCipher params: s=${obfuscatedSig != null}, url=${baseUrl != null}")
            return null
        }

        ResolverLog.tag(TAG).d("Deobfuscating cipher for $videoId: sig=${obfuscatedSig.take(20)}..., sp=$sigParam")

        val webView = getOrCreateWebView(forceRefresh = isRetry)
            ?: return null

        val deobfuscatedSig = webView.deobfuscateSignature(obfuscatedSig)

        val separator = if ("?" in baseUrl) "&" else "?"
        val finalUrl = "$baseUrl${separator}${sigParam}=${UriCodec.encode(deobfuscatedSig)}"

        ResolverLog.tag(TAG).d("Custom cipher deobfuscation succeeded for $videoId")
        return finalUrl
    }

    suspend fun transformNParamInUrl(url: String): String {
        return try {
            transformNInternal(url)
        } catch (e: Exception) {
            ResolverLog.tag(TAG).e(e, "N-transform failed, returning original URL: ${e.message}")
            url
        }
    }

    private suspend fun transformNInternal(url: String): String {

        val nMatch = Regex("[?&]n=([^&]+)").find(url)
        if (nMatch == null) {
            ResolverLog.tag(TAG).d("No 'n' parameter found in URL, skipping transform")
            return url
        }
        val nValue = UriCodec.decode(nMatch.groupValues[1])
        ResolverLog.tag(TAG).d("N-param found: $nValue")

        val webView = getOrCreateWebView(forceRefresh = false) ?: return url

        if (!webView.nFunctionAvailable) {
            ResolverLog.tag(TAG).e("N-transform function was not discovered at init time")
            return url
        }

        val transformedN = webView.transformN(nValue)
        ResolverLog.tag(TAG).d("N-param transformed: $nValue -> $transformedN")

        return url.replaceFirst(
            Regex("([?&])n=[^&]+"),
            "$1n=${UriCodec.encode(transformedN)}"
        )
    }

    private suspend fun getOrCreateWebView(forceRefresh: Boolean): CipherSession? {
        if (!forceRefresh && cipherWebView != null) {
            return cipherWebView
        }

        if (cipherWebView != null) {
            closeWebView()
        }

        val result = PlayerJsFetcher.getPlayerJs(forceRefresh = forceRefresh)
        if (result == null) {
            ResolverLog.tag(TAG).e("Failed to get player JS")
            return null
        }
        val (playerJs, hash) = result

        val sigInfo = FunctionNameExtractor.extractSigFunctionInfo(playerJs)

        if (sigInfo == null) {
            ResolverLog.tag(TAG).e("Could not extract signature function info from player JS")
            return null
        }

        val nFuncInfo = FunctionNameExtractor.extractNFunctionInfo(playerJs)
        if (nFuncInfo == null) {
            ResolverLog.tag(TAG).e("Could not extract n-function info from player JS (will try brute-force)")
        }

        ResolverLog.tag(TAG).d("Creating CipherWebView with sig=${sigInfo.name}, constantArg=${sigInfo.constantArg}, nFunc=${nFuncInfo?.name}[${nFuncInfo?.arrayIndex}]")

        val webView = ResolverRuntime.platform.jsRuntime.loadCipher(
            playerJs = playerJs,
            sigInfo = sigInfo,
            nFuncInfo = nFuncInfo,
        )

        cipherWebView = webView
        currentPlayerHash = hash
        return webView
    }

    private suspend fun closeWebView() {
        cipherWebView?.dispose()
        cipherWebView = null
        currentPlayerHash = null
    }

    private fun parseQueryParams(query: String): Map<String, String> {
        val result = mutableMapOf<String, String>()
        for (pair in query.split("&")) {
            val idx = pair.indexOf('=')
            if (idx > 0) {
                val key = UriCodec.decode(pair.substring(0, idx))
                val value = UriCodec.decode(pair.substring(idx + 1))
                result[key] = value
            }
        }
        return result
    }

    /** Forgets the loaded player so the next call reloads it. Tests only. */
    internal fun resetForTests() {
        cipherWebView = null
        currentPlayerHash = null
    }
}
```

```kotlin
package com.example.musicfy.utils.potoken

import com.example.musicfy.core.resolver.BotGuardRuntime
import com.example.musicfy.core.resolver.BotGuardSession
import com.example.musicfy.core.resolver.ResolverLog
import com.example.musicfy.core.resolver.ResolverRuntime
import kotlinx.coroutines.runBlocking
import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock

class PoTokenGenerator(
    private val runtime: () -> BotGuardRuntime = { ResolverRuntime.platform.botGuardRuntime },
) {
    private val TAG = "PoTokenGenerator"

    /**
     * Any well-known video id works to boot the engine; the resulting player token is discarded
     * and only the session token it mints alongside is kept.
     */
    private val PREWARM_VIDEO_ID = "dQw4w9WgXcQ"

    private companion object {
        const val MINT_COOLDOWN_MS = 5 * 60 * 1000L
    }

    private val webViewSupported by lazy { runtime().isSupported }
    private var webViewBadImpl = false

    /**
     * After a failed mint we stop trying for a while. A cold start costs up to 45 seconds, and
     * paying that on every single track turns a broken BotGuard into a player that looks frozen.
     */
    @Volatile
    private var mintCooldownUntilMs = 0L

    private val webPoTokenGenLock = Mutex()
    private var webPoTokenSessionId: String? = null
    private var webPoTokenStreamingPot: String? = null
    private var webPoTokenGenerator: BotGuardSession? = null

    /** True once a session token has been minted, so diagnostics can show the real state. */
    val hasSessionToken: Boolean
        get() = webPoTokenStreamingPot != null && webPoTokenGenerator?.isExpired == false

    /**
     * Boot the BotGuard engine ahead of playback.
     *
     * A cold start costs tens of seconds. Paying that inside the ExoPlayer resolver stalls the
     * first track, and if it gives up we fall through to a client that can only serve YouTube's
     * ~32 second preview window - so the cold start itself can look like a playback bug.
     */
    suspend fun preWarm(sessionId: String) {
        if (poTokenFor(PREWARM_VIDEO_ID, sessionId) != null) {
            ResolverLog.tag(TAG).d("PoToken pre-warm complete")
        } else {
            ResolverLog.tag(TAG).w("PoToken pre-warm did not produce a token")
        }
    }

    /**
     * Suspend entry point. Prefer this on the playback path - the blocking variant pins the
     * ExoPlayer loading thread for however long BotGuard takes.
     */
    suspend fun poTokenFor(videoId: String, sessionId: String): PoTokenResult? {
        if (!webViewSupported || webViewBadImpl) return null
        if (System.currentTimeMillis() < mintCooldownUntilMs) {
            ResolverLog.tag(TAG).d("Skipping poToken mint - cooling down after a failure")
            return null
        }
        return try {
            getWebClientPoToken(videoId, sessionId, forceRecreate = false)
        } catch (e: BadWebViewException) {
            ResolverLog.tag(TAG).e(e, "Could not obtain poToken because WebView is broken")
            webViewBadImpl = true
            null
        } catch (e: Exception) {
            ResolverLog.tag(TAG).e(e, "poToken generation failed: ${e.javaClass.simpleName}: ${e.message}")
            startMintCooldown()
            null
        }
    }

    private fun startMintCooldown() {
        mintCooldownUntilMs = System.currentTimeMillis() + MINT_COOLDOWN_MS
    }

    fun getWebClientPoToken(videoId: String, sessionId: String): PoTokenResult? {
        ResolverLog.tag(TAG).d("getWebClientPoToken called: videoId=$videoId, sessionId=$sessionId")
        ResolverLog.tag(TAG).d("WebView state: supported=$webViewSupported, badImpl=$webViewBadImpl")
        if (!webViewSupported || webViewBadImpl) {
            ResolverLog.tag(TAG).d("WebView not available: supported=$webViewSupported, badImpl=$webViewBadImpl")
            return null
        }

        return try {
            ResolverLog.tag(TAG).d("Calling runBlocking to generate poToken...")
            runBlocking { getWebClientPoToken(videoId, sessionId, forceRecreate = false) }
        } catch (e: Exception) {
            ResolverLog.tag(TAG).e(e, "poToken generation exception: ${e.javaClass.simpleName}: ${e.message}")
            when (e) {
                is BadWebViewException -> {
                    ResolverLog.tag(TAG).e(e, "Could not obtain poToken because WebView is broken")
                    webViewBadImpl = true
                    null
                }
                else -> throw e
            }
        }
    }

    private suspend fun getWebClientPoToken(videoId: String, sessionId: String, forceRecreate: Boolean): PoTokenResult {
        ResolverLog.tag(TAG).d("Web poToken requested: videoId=$videoId, sessionId=$sessionId")

        val (poTokenGenerator, streamingPot, hasBeenRecreated) =
            webPoTokenGenLock.withLock {
                val shouldRecreate =
                    forceRecreate ||
                        webPoTokenGenerator == null ||
                        webPoTokenGenerator!!.isExpired ||
                        webPoTokenStreamingPot == null ||
                        webPoTokenSessionId != sessionId

                if (shouldRecreate) {
                    ResolverLog.tag(TAG).d("Creating new PoTokenWebView (forceRecreate=$forceRecreate)")
                    webPoTokenSessionId = sessionId

                    webPoTokenGenerator?.dispose()

                    webPoTokenGenerator = null
                    webPoTokenStreamingPot = null

                    val generator = runtime().newSession()
                    webPoTokenStreamingPot = try {
                        generator.generatePoToken(webPoTokenSessionId!!)
                    } catch (e: Exception) {
                        runCatching { generator.dispose() }
                        throw e
                    }
                    webPoTokenGenerator = generator
                    ResolverLog.tag(TAG).d("Streaming poToken generated for sessionId=${webPoTokenSessionId?.take(20)}...")
                }

                Triple(webPoTokenGenerator!!, webPoTokenStreamingPot!!, shouldRecreate)
            }

        val playerPot = try {
            poTokenGenerator.generatePoToken(videoId)
        } catch (throwable: Throwable) {
            if (hasBeenRecreated) {

                throw throwable
            } else {

                ResolverLog.tag(TAG).e(throwable, "Failed to obtain poToken, retrying")
                return getWebClientPoToken(videoId = videoId, sessionId = sessionId, forceRecreate = true)
            }
        }

        ResolverLog.tag(TAG).d("poToken generated: session=${streamingPot.take(20)}... video=${playerPot.take(20)}...")

        // Session token in the player request, video token on the stream url - see PoTokenResult.
        return PoTokenResult(
            playerRequestPoToken = streamingPot,
            streamingDataPoToken = playerPot,
        )
    }
}
```

```kotlin
object BotDetectionMitigator {
    private const val TAG = "BotDetectionMitigator"

    private val failureCount = AtomicInteger(0)

    private val GEO_ERROR_SIGNATURES = listOf(
        "not available in your country",
        "not available in your region",
        "not available in this country",
        "not available in this region",
        "geo-restricted",
        "GEO_RESTRICTED",
        "NOT_AVAILABLE_IN_THIS_COUNTRY",
        "only available in certain countries",
        "country restriction",
        "region restriction",
    )

        "confirm you're not a bot",
        "automated queries",
        "Error 2000",
        "403",
        "This content isn't available on this device",
    )

    fun notifyPlaybackFailure(isLoggedIn: Boolean, errorMessage: String? = null): Boolean {
        if (isLoggedIn) return false
        if (isGeoError(errorMessage)) return false

        failureCount.incrementAndGet()
        return true
    }

    fun notifyPlaybackSuccess() {
        failureCount.set(0)
    }

    suspend fun rotateGuestSession() {
        ResolverLog.tag(TAG).i("Rotating guest session to bypass bot detection...")
        PlaybackLogManager.log(
            PlaybackLogLevel.BOT,
            "Rotating guest session",
            "Bypassing bot detection by refreshing visitorData (locale preserved)"
        )

        withContext(Dispatchers.IO) {

            val currentLocale = YouTube.locale

            YouTube.visitorData = null

            ResolverRuntime.platform.backend.refreshVisitorData().onSuccess { newData ->
                ResolverLog.tag(TAG).i("New visitorData obtained successfully for region ${currentLocale.gl}.")

                ResolverRuntime.platform.onVisitorDataRotated(newData)
            }.onFailure { e ->
                ResolverLog.tag(TAG).e(e, "Failed to refresh visitorData during rotation")

                YouTube.locale = currentLocale
            }
        }

        failureCount.set(0)
    }

    fun isGeoError(message: String?): Boolean {
        if (message == null) return false
        val lower = message.lowercase()
        return GEO_ERROR_SIGNATURES.any { lower.contains(it.lowercase()) }
    }

    fun isBotDetectionError(message: String?): Boolean {
        if (message == null) return false
        val lower = message.lowercase()
        return BOT_ERROR_SIGNATURES.any { lower.contains(it.lowercase()) }
    }

    fun reset() {
        failureCount.set(0)
    }
}
```

```kotlin
    val recentQueries: List<String> = emptyList(),
    val contentCountry: String? = null,
    val error: String? = null,
)

fun interface SongSearch {
    suspend fun search(query: String): Result<List<SongItem>>
}

object InnerTubeSongSearch : SongSearch {
    override suspend fun search(query: String): Result<List<SongItem>> =
        YouTube.search(query, YouTube.SearchFilter.FILTER_SONG).map { result -> result.items.filterIsInstance<SongItem>() }
}

/** The skeleton's only screen logic: search InnerTube, remember queries in the DB, show a setting. */
class SearchController(
    private val search: SongSearch,
    private val dao: DesktopDao,
    private val settings: DataStore<Preferences>,
    private val scope: CoroutineScope,
) {
    private val _state = MutableStateFlow(SearchUiState())
    val state: StateFlow<SearchUiState> = _state.asStateFlow()

    fun start(): Job = scope.launch {
        val country = settings.data.first()[ContentCountryKey]
        _state.update { it.copy(contentCountry = country) }
        dao.searchHistory().collect { history ->
            _state.update { it.copy(recentQueries = history.map(SearchHistory::query)) }
        }
    }

    fun onQueryChange(query: String) = _state.update { it.copy(query = query) }

    fun submit(): Job = scope.launch {
        val query = _state.value.query.trim()
        if (query.isEmpty()) return@launch
        _state.update { it.copy(loading = true, error = null) }
        dao.insert(SearchHistory(query = query))
        search.search(query)
            .onSuccess { songs -> _state.update { it.copy(loading = false, results = songs) } }
            .onFailure { e -> _state.update { it.copy(loading = false, error = e.message ?: e::class.simpleName) } }
    }
}
```

```kotlin
@Composable
fun SearchScreen(controller: SearchController) {
    val state by controller.state.collectAsState()
    Surface(color = MaterialTheme.colorScheme.background, modifier = Modifier.fillMaxSize()) {
        Column(Modifier.fillMaxSize().padding(24.dp)) {
            Text("Musicfy", style = MaterialTheme.typography.headlineMedium)
            Text(
                "Content country: ${state.contentCountry ?: "default"}",
                style = MaterialTheme.typography.bodySmall,
            )
            Row(verticalAlignment = Alignment.CenterVertically) {
                OutlinedTextField(
                    value = state.query,
                    onValueChange = controller::onQueryChange,
                    singleLine = true,
                    label = { Text("Search songs") },
                    modifier = Modifier.weight(1f),
                )
                Spacer(Modifier.width(12.dp))
                Button(onClick = { controller.submit() }, enabled = !state.loading) { Text("Search") }
            }
            if (state.recentQueries.isNotEmpty()) {
                Text(
                    "Recent: " + state.recentQueries.take(5).joinToString(" · "),
                    style = MaterialTheme.typography.bodySmall,
                )
            }
            state.error?.let { Text(it, color = MaterialTheme.colorScheme.error) }
            if (state.loading) LinearProgressIndicator(Modifier.fillMaxWidth())
            LazyColumn(Modifier.fillMaxSize()) {
                items(state.results, key = { it.id }) { song ->
                    ListItem(
                        headlineContent = { Text(song.title) },
                        supportingContent = { Text(song.artists.joinToString { it.name }) },
                    )
                }
            }
        }
    }
```
